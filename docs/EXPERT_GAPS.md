# 专业维度与证据缺口

这是一份卡库的覆盖审查与补证建议，不是专家验收，也不是完整的美术、电影或交互设计教材。目标是让模型知道“当前卡片能帮助做哪一种决定，以及还不能据此声称什么”。

本轮以原报告 `2026-10-25-repo-design-cards/cards.json` 的 257 张案例卡、24 张主卡为基础。证据标签为 `source_only` 171 张、`still_observed` 86 张；没有标为 `motion_observed` 或 `runtime_verified` 的卡。源码机制、作者历史图与本轮实际运行是不同证据；精确行号和哈希只保证来源可追踪，不保证美术效果、性能、声音或可用性已经通过。

[六条设计轨迹](../data/editorial/trajectories.json) 是本轮新增的编排建议，30 个步骤引用 64 张实际案例卡。它们把先决问题和失败回退写出来，没有增加运行证据。轨迹可以分支和删减，不要求一次使用全部引用卡：每步先选能回答当前问题的最小案例，条件不满足就采用邻近方法或跳过可选效果，并记录原因。

## 新增归纳视角与新增验证分开

| 层次 | 本轮新增了什么 | 不能推出什么 |
| --- | --- | --- |
| 案例 | 保留具体来源、参数、适用条件与失败模式 | 一个仓的成功图片不证明跨场景通用 |
| 主卡 | 把相近案例归纳为共同动作和不同实现分支 | 24 个主题不是已被实验证明的设计定律 |
| 轨迹 | 明确先解决什么、下一步为什么依赖它、何时应回退 | 有检查条件不代表检查已执行 |
| 专业维度 | 加入跨案例审视形体、空间、材料、镜头、时间与任务的提问方式 | 添加一个分类不等于填补其知识与证据缺口 |
| 后续验证 | 需要新的对照图、动态片段、交互记录或听审结果 | 作者截图、测试名称和渲染成功不能代替实际观察 |

轨迹按目标领域组织，不按引擎或模型品牌组织：

| 轨迹 | 核心依赖关系 | 可查主卡 |
| --- | --- | --- |
| TR-01 雨夜街 | 视廊与身份 → 光源响应 → 暴露关系 → 湿润 → 动态观察 | MP-03、MP-06、MP-08、MP-09 |
| TR-02 海岸 | 地形块面 → 波长职责 → 天空/水一致 → 退潮记忆 | MP-04、MP-05、MP-23 |
| TR-03 微缩建筑 movie | 建筑身份 → 支撑与净空 → 镜头任务 → 安全轨道 → 时间采样 | MP-09、MP-10、MP-11、MP-19 |
| TR-04 液态品牌片 | 可读终态 → 形态对应 → 动作句子 → 局部光学 → 反例裁决 | MP-07、MP-13、MP-19、MP-24 |
| TR-05 列表详情 | 基础阅读 → 同一对象 → 就绪接管 → 返回与焦点 → 任务完成 | MP-13、MP-14、MP-15、MP-20、MP-21 |
| TR-06 世界复苏 | 可操作锚点 → 实际路线 → 完成事件 → 世界变化 → 可退出回望 | MP-01、MP-11、MP-16、MP-23 |

这里的顺序来自依赖关系。例如“先主体后材质”能避免用表面效果掩盖轮廓问题；但如果任务本身是材质研究，完全可以锁定已有形体，从材质步骤开始。每条轨迹中的问题和检查条件比固定顺序更重要。

## 目前证据不足的专业维度

### 1. 角色形体、解剖与表演造型

**已有切口：** ATH-003 涉及雕塑头/身体的精度分配；CN-002、CN-014、CN-016 涉及表情寿命和冲突；CN-020 涉及有限嘴形估计。它们主要解决几何分配和状态调度。

**不足：** 不能据此评价骨骼比例、肌肉与软组织、姿势重心、面部结构、衣褶受力、绑定变形或表演可信度。雕像某张图有可辨头像，不等于解剖正确；口型状态切换也不是语音表演验收。

**新增归纳视角：** 把“身份可辨”“形体成立”“动作可信”“状态正确”分成四种问题，避免用面数或表情数量回答全部问题。

**最小补证：** 若目标确需该维度，选择一个合法角色/雕像，提交正侧背和同焦距近景、灰模轮廓、两个负重姿态；有动画时补关节极限与三种情绪短片，由有相关经验的人员逐项记录结构与表演意见。当前 hIE 保持 2D 的目标不因这个缺口自动改为 3D；2D 仍可检查表情、口型与姿态是否表达一致。

### 2. 建筑比例、构造可信度与环境叙事

**已有切口：** ATH-001/002、MOME-001、SD-IC03、SD-TW01/02/03 提供开口节律、接地、支撑、使用痕迹和净空方法。

**不足：** 尚未证明建筑比例、结构逻辑或历史风格准确；宏观接地不保证细部连接成立，规则散布也不能自动形成可信使用故事。按主机位优化的布局可能从其他方向露出问题。

**新增归纳视角：** 分开问“如何建成”“如何进入”“如何使用”“为何磨损”，让污渍和道具密度有原因。

**最小补证：** 选一栋英雄建筑，提供米制尺寸、四面视图、入口到使用区的连续路径，以及三处受力/连接细节；每类风化标记其水流、触碰或维护原因。此为视觉构造评审，不升级为工程安全认证。

### 3. 材质测量、色彩管理与输出一致性

**已有切口：** REN-007 的同灯粗糙度阶梯、SHOW-002 的共享纹理结构、LIVE-002 的亮度分区调色、SD-TW01 的实尺度材质；多个案例提醒线性/HDR 与 sRGB 的边界。

**不足：** 未做完整输入纹理解释、线性合成、曝光、tone mapping、显示转换和视频编码的端到端核验。源码有 ACES 或 `sRGB` 字样不证明没有双重转换；视觉上“湿亮”也不说明粗糙度或能量响应正确。

**新增归纳视角：** 区分材料身份、照明响应和最终显示调色，不把它们都叫“颜色”。

**最小补证：** 在同一已记录管线中放中性灰、色块、粗糙度/金属度阶梯，固定灯与曝光，对照纹理输入、线性输出、显示图和成片解码帧。记录每一转换及观看环境。没有校准显示或实测参考时，只报告工程一致性与该环境内的视觉判断。

### 4. 摄影机镜头、光学近似与构图语言

**已有切口：** ATH-005、MOME-004/005、FM-013/014 提供构图、轨道、焦点和有限景深；NWR-002、MF-013、SEA-005 分别处理不同类型的折射或光路近似。

**不足：** 这些不是一套完整摄影光学模型，也未系统覆盖传感器尺寸/焦距对应、真实镜头畸变、焦点呼吸、曝光取舍、视线与屏幕方向连续性。MOME 的景深按画幅限制，不能仅因注释写“physically exact”就视为实相机标定；黑洞、玻璃和屏幕扭曲不可混成同一种物理机制。

**新增归纳视角：** 分开选择“这一镜要让人看什么”“镜头如何移动”“光学模型允许什么误差”。

**最小补证：** 同一主体制作固定机位的视场/距离/景深小矩阵，保持目标屏幕尺寸可比；记录焦平面和近远物的遮挡。对拟称物理真实的效果另找对应标定或可信参考。没有这类证据时，保留“可控风格化近似”标签。

### 5. 动态观感、剪辑连续性与长段节奏

**已有切口：** MP-11/12/19、CN-026/027、MF-001/007、NWR-003 细化了停顿、动作、速度和采样。源代码能说明意图，历史静帧无法说明观众实际感受。

**不足：** 当前没有新增连续片段观察标签；没有系统验证镜头加减速、动作重心、转场跨镜污染、跳切、反复循环、长时间眩晕或注意疲劳。数学连续不等于观感自然，插值不超调也不等于相机避障。

**新增归纳视角：** 对每段写出建立信息、发生变化、确认结果的时间职责，并区分局部曲线与跨镜节奏。

**最小补证：** 每次选择一个完整观看段，保留正常速度、关键帧与帧时间记录；至少覆盖首尾、切镜点、最快运动和一次暂停/恢复。两版只改一个待裁决因素，记录何处改善/恶化。长循环目标另补连续观察，短片通过不能代替长时舒适性判断。

### 6. 声音设计、音乐结构与混音

**已有切口：** SD-LR05、SD-TW05、MF-005、NI-001 有视觉事件与声音时钟、空间声或配器层级；CN 系列含语音顺序和中断语义。

**不足：** 本轮没有实际试听与音画同步审片。事件表存在不证明听得到、好听或无遮蔽；音频参数与作者响度报告不构成本轮混音验证。代码中声明音轨类型也不保证渲染器确实播放该轨。

**新增归纳视角：** 分开功能提示、环境连续性、叙事重音、对白可懂度和配乐情绪，不把“有声音”当一个总项。

**最小补证：** 选择已有合法音频的一段，提供无声画面、声音分轨和最终混音；试听耳机与普通扬声器，标注事件对齐、对白遮蔽、重复触发、停播恢复及峰值异常。声音尚未授权或素材缺失就保留未验证，不补虚构听感结论。

### 7. 交互可用性、可访问性与长时状态

**已有切口：** FM-024/026/028、SHOW-020、NI-003、MP-15/20/21 关注真实加载、阅读、焦点、减少运动和回退；NWR-009 区分即时与持久状态。

**不足：** 还没有代表性任务测试、辅助技术使用记录、长会话/跨页/离线恢复证据，不能声称完整可访问性或可靠性。单个 `tabIndex`、媒体查询或错误提示只覆盖局部；所有操作都能被鼠标演示不代表键盘、触摸或读屏成立。

**新增归纳视角：** 把美感建立在任务状态可理解、对象身份稳定、输入权属于用户三个前提上，再讨论动效强弱。

**最小补证：** 为一个列表详情或世界交互完成主任务与失败恢复，记录键盘、触摸、减少运动、文字放大和至少一种适用辅助技术的表现；再加慢网、离线、切后台与多次返回。若目标是长时产品，另做持续会话与状态恢复，不能由短演示推定通过。

### 8. 空间安全、物理因果与模拟边界

**已有切口：** SYS-002/008/009、ATH-002、MOME-004 与 NWR-005 提供接地、净空、碰撞和路线约束；OCN-003、SD-LR01 处理空间痕迹。

**不足：** 不同方法覆盖的几何尺度不同：单层高度图不表达桥下，地形五点采样不避开高楼，路线简化可能切角，闭式粒子缺少真实惯性。不能把这些限制合并成“已有统一物理系统”。

**新增归纳视角：** 为每个效果标清它依赖的是屏幕、表面、体积、时间历史还是业务事件；需要什么事实就查对应事实。

**最小补证：** 选平地、斜坡、窄缝、桥下、高楼五类适用反例，只测目标机制承担的约束；记录未覆盖形状。美术近似若不影响目标镜头可保留，但必须与物理保证分开。

### 9. 艺术方向、参考选择与审美分歧

**已有切口：** MP-07、NF-005/006/008、NWR-004 提供定位变更、依赖检查与反例裁决；卡片已经避免把所有案例都判为优先迁移。

**不足：** 数量多、跨仓出现或像某张参考，不代表形成了一致艺术方向。尚无针对同一 brief 的多方案盲评与分歧记录；“高质量”缺少目标人群、观看场景与表达目的时容易变成效果堆叠。

**新增归纳视角：** 先写一段表达意图和两三项不能牺牲的属性，例如压迫感但出口可读、温暖但保留夜色、轻盈但材质有重量。然后才抽卡。

**最小补证：** 同一 brief 做两版有明确差异的构图/材料方案，固定其他变量；请相关创作者或目标使用者说明更适合哪一版、依据和代价。记录分歧和适用场景，不把票数当普遍美学真理。引用图仅作为研究参考时，不自动取得复制或发布权。

### 10. 交付保真、运行环境与资产边界

**已有切口：** SD-OT02/03/04、SYS-003/004/007、MP-22 处理资产烘焙、模型简化、接缝与表示替换；多仓已记录代码和媒体分开的许可边界。

**不足：** 当前没有证明从源 DCC/程序场景到目标项目、再到用户设备或视频输出时完全保真。源仓构建成功、作者高帧率和模型品牌均不是本轮结果；整仓 MIT 也不能自动覆盖外部图、模型、音乐、地理数据或商标。

**新增归纳视角：** 把创作原件、网页交付资产、预览质量与最终输出分开审查；先守住身份、轮廓和材质，再谈性能削减。

**最小补证：** 选一个英雄资产，比较原件、导出、目标场景的同机位图，核对法线、透明边缘、UV尺度、灯与色彩；登记输入版本与许可。再在实际目标环境记录表现。性能优化依照项目阶段后置，不以优化替代尚未完成的形体与材质工作。

## 最小补证记录

每次只补当前轨迹真正需要的缺口。建议留一份小记录，字段可以是 Markdown 或 JSON，不要求先搭新系统：

- **目标与卡片：** 当前表达/任务问题、引用 ID，以及要验证的具体主张。
- **固定条件：** 相机、光照、尺寸、设备、资产版本、seed、时间范围；没有固定的项注明。
- **变更和反例：** A/B 只改变什么；哪种故意错误应能被识别。
- **观察材料：** 实际看过的静图、连续片段、交互轨迹或实际听过的音轨与范围。
- **结论：** 保留、改造、回退或仍未知；写可定位原因及已知代价。
- **未覆盖：** 其他机位、设备、声音、辅助技术、长时状态和许可等待等，不把空白算通过。

只有产生并实际检查了新的材料，才能提高对应案例的证据阶段。主卡和轨迹可以继续改进组织方式，而不提高任何证据等级。某个方向暂时没有足够素材，就保留缺口，不为了“专业体系完整”强造一张卡。
