# 巨像越画框

分组：造型尺度 · 主维度：D 局部识别、C 果断裁切、G 近身透视、A 轮廓可读、I 压迫 · 情绪：压迫、敬畏

## 一句话

只让巨物的一部分进入画面，同时留下熟悉轮廓，观众会主动补全框外的体量。

1. 云上石像：膝与手臂越出下方和右边，脸与手势仍足以确认巨大人形。
2. 中式幻想 RPG · 雾中巨像：两侧巨像的冠顶和身体被边框截断，中间水道仍能通行。
3. Unreal 云上神殿与巨龙：巨龙头与长须挤入近景，廊柱和小人物提供另一个尺度。

## 拆解

比例为截图目估；三张均为实际观看过的独立视频画面，不宣称模型资产彼此独立。

- **D · 识别线索**：石像保留头、肩与手，龙保留下颌、角和须；不是随便截一块无从辨认的表面。局部已经足以激活整体形状。
- **C · 出框位置**：石像下肢与右臂越出下/右边，雾像越出上边和侧边；不能把所有最重要的轮廓同时截掉。中央亮口在雾像图约占宽1/4。
- **G · 透视**：石像从低处向上看，近膝与脸大小明显不同；这是近身视点而不是长焦平视头像。准确焦距未知，不能由图报出原作FOV。
- **A · 边界**：浅石像靠蓝天分离，深雾像靠淡灰背景分离；截断处之外仍需有可读的连续边缘。
- **I · 身体经验**：船棚与人把观众留在普通尺度，巨物才显得不可一眼看完。没有地面/小物参照时，裁切也可能只像产品特写。

## 做法

先让巨物在场景中拥有完整可信体积，再选择相机位置裁入；不要仅做一张贴脸的巨大平面。预留模型框外部分以便轻微视差不露馅。

- **迁移试验**：从一个熟悉小物的视高出发，逐步靠近，让巨物约1/4–1/2延出画框；脸/手势/门拱等关键识别线保留至少一组。这是构图建议而非测量原作裁切率。
- 禁止依赖强景深把背景全抹掉来假装尺度，先在清楚的灰模里成立。

## 迁移到博客

Shrine（`shrine-1`）会面背景可让像身出框但保留手与脸；BlackCity（`black-city-1`）可借工业立面出框保留门窗。title 已锁定，不纳入本批迁移。2D人物不能被巨大前景无意遮脸，取景需结合角色层一起看。

搭配熟悉物标定巨构、逆光露轮廓；与“全场景一眼看完”的俯瞰地图属于不同机位目标，不在同一镜头强求两者。
