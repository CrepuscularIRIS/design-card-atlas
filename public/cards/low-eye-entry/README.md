## 拆解

百分比与颜色为画面目估，非渲染器测量。

- G：巨像图视点接近船与人物高度，向上看柱像；Sakura视点略高于近船而低于坡顶。只判断可见视点关系，不能由单帧反推出毫米焦距。
- C：巨像通路在右侧约60%横向位置，Sakura水路折向右上，Warp趋近中央；路径不必绝对对称，但必须有明确去向。
- D：近船/两侧楼体被果断裁断，屏幕边缘不交代它们的完整轮廓；因此它们像观众身边的物，而不是被展示的小模型。此卡关注相机位置，熟悉物尺度的专门方法见对应D卡。
- F：巨像的雾减少远处反差；Sakura桥脚低雾与湿河反光把近船和远塔分开。通道中央保留明度差，不把全部空间填成同一团雾。
- I：深处必须留下值得到达的对象：巨像之后的洞口、河上红桥、城市尽头的天体/航点。留出前进欲望比满屏装饰更有效。

## 做法

先放低相机并把一件近物移到画边，再检查河岸/道路是否自然把目光带到远处。镜头可以不动，入场感先由视点成立。

建议起点：近物占画宽20–40%，通路在画中保持约20–35%的可读开口；眼高先接近角色/船上视点，再逐步调整。数值是构图试验建议，不是原作源码参数。

本卡只给构图/排版迁移建议，不将未知源码值补成精确参数。
