# 视觉语言拆解维度

（拆解与归卡都用这张表）

每张卡在「拆解」一节里，挑出起作用的维度逐条写，至少 4 个维度。每条都要落到图上的具体位置，并尽量给数值（hex、比例、角度、亮度百分比）。

### A. 光影
| 维度 | 要回答的问题 |
|---|---|
| 主光方向 | 顺光 / 侧光 / 逆光 / 顶光 / 底光？主光在画面哪里？ |
| 光源类型 | 太阳、天光、发光体（霓虹、屏幕、吸积盘）、点光、体积光？ |
| 光比与明暗结构 | 暗部占画面多少？最亮点在哪？是低调（大面积暗）还是高调？ |
| 轮廓光 / 边缘光 | 主体边缘有没有一圈光把它从背景里分出来？颜色？ |
| 阴影 | 硬阴影还是软阴影？接触阴影/AO 是否让物体落地？ |
| 发光与光晕 | bloom 的阈值和扩散范围？光晕是否吃掉结构？ |
| 光的叙事 | 光把视线引到哪？光是否在讲时间（黄昏、深夜、事件发生）？ |
| 反射与高光 | 高光形状、反射里能看到什么？ |

### B. 色彩
| 维度 | 要回答的问题 |
|---|---|
| 主色与辅色 | 画面由哪 1–2 个色相主导？给出 hex |
| 冷暖关系 | 冷暖如何分区（暖光冷影 / 冷环境暖焦点）？ |
| 饱和度分布 | 高饱和只出现在哪里？大面积是否降饱和？ |
| 明度阶梯 | 黑、暗灰、中灰、亮、高光各占多少？ |
| 调色风格 | tone mapping 曲线、色偏、胶片颗粒、色差？ |
| 点缀色 | 有没有一个小面积强对比色做视觉锚点？ |

### C. 构图与重心
| 维度 | 要回答的问题 |
|---|---|
| 视觉重心 | 第一眼落在哪？第二眼沿什么路径走？ |
| 主体位置 | 居中对称 / 三分 / 极端偏置 / 地平线位置？ |
| 负空间 | 留白（或留暗）占多少？负空间在帮谁？ |
| 引导线 | 道路、建筑边线、光柱、水面反光带是否把视线引到主体？ |
| 前中后景 | 三层各是什么？有没有前景遮挡增加纵深？ |
| 画框与比例 | 横幅宽银幕 / 竖幅 / 画中画？裁切是否果断？ |
| 平衡 | 对称稳定还是不对称张力？重量如何左右/上下分配？ |

### D. 造型与尺度
| 维度 | 要回答的问题 |
|---|---|
| 剪影 | 关掉纹理只看轮廓，主体还能认出来吗？ |
| 尺度对比 | 用什么参照物显出「巨大」（人、车、窗格、云）？ |
| 体块组织 | 大—中—小三级形体的比例与节奏？ |
| 细节密度分布 | 细节集中在哪里？哪里刻意留空？ |
| 重复与节奏 | 阵列、柱廊、窗格、层叠带来的韵律？ |
| 风格语汇 | 粗野主义、赛博、哥特、东方古建、有机/硬表面？ |

### E. 材质与表面
| 维度 | 要回答的问题 |
|---|---|
| 粗糙度 | 镜面、半光、哑光如何分布？ |
| 金属感 | 金属/非金属的对比？ |
| 状态 | 湿、干、积尘、风化、锈蚀、磨损，从哪些线索读出来？ |
| 微结构 | 法线细节、划痕、拉丝、混凝土孔洞？ |
| 透明/半透 | 玻璃、水、全息、次表面散射？ |
| 发光材质 | 自发光线条、屏幕、符文，亮度与面积？ |

### F. 水、流体与大气
| 维度 | 要回答的问题 |
|---|---|
| 水面 | 镜面 / 波浪 / 浅滩 / 积水？反射清晰度？菲涅尔？ |
| 湿地面 | 拉长的灯光倒影、水渍边缘？ |
| 雾 | 距离雾 / 高度雾 / 局部雾团？颜色取自哪？ |
| 体积光 | god rays 方向、强度、是否被遮挡物切开？ |
| 粒子 | 雨、雪、尘、萤火、星点？密度和运动方向？ |
| 天空与背景 | 天体（黑洞、行星、月亮）、星云、渐变天空、云海？ |

### G. 镜头与运动
| 维度 | 要回答的问题 |
|---|---|
| 焦距与透视 | 广角夸张透视 / 长焦压缩？视点高低（仰视显巨大）？ |
| 景深 | 焦点在哪？虚化程度？ |
| 镜头运动 | 推、拉、摇、移、环绕、升降？起止点各给观众看什么？ |
| 节奏曲线 | 停顿—加速—缓停？时长？ |
| 转场 | 硬切、溶解、匹配剪辑、对象延续？ |
| 场景动态 | 什么在动（光、水、粒子、人群）？快慢对比？ |
| 动态模糊/拖影 | 有没有，用来表达什么？ |

### H. 排版与 UI（3D 之上的 2D 层）
| 维度 | 要回答的问题 |
|---|---|
| 字体性格 | 衬线 / 无衬线 / 等宽 / 书法 / 中日文字体？字重对比？ |
| 字号层级 | 巨字、标题、正文、标注的比例？ |
| 文字与画面关系 | 压在画面上 / 留白区 / 跟随 3D 物体 / 被遮挡？ |
| 网格与对齐 | 栅格、边距、对齐线？ |
| UI 语汇 | HUD 细线、角标、刻度、扫描线、坐标编号？ |
| 信息密度 | 克制留白还是信息密集仪表盘？ |
| 交互反馈 | hover、选中、过渡的视觉形式？ |

### I. 氛围与叙事
| 维度 | 要回答的问题 |
|---|---|
| 情绪关键词 | 孤寂、压迫、神圣、末日、宁静、躁动……选 1–3 个 |
| 时间与天气 | 黄昏、深夜、暴雨、事件发生瞬间？ |
| 世界观暗示 | 画面里有哪些细节让人相信这是一个完整的世界？ |
| 克制 | 刻意没做什么（不加光晕、不加 UI、不加粒子）？ |
